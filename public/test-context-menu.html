🧪 Test Context Menu - EasyDaddy

📋 Инструкция по тестированию контекстного меню:

  1. Установите расширение EasyDaddy
  2. Создайте профиль с тестовыми данными
  3. Нажмите правой кнопкой мыши в любом месте этой страницы
  4. Найдите пункт "EasyDaddy - Fill Forms" в контекстном меню
  5. Выберите этот пункт - формы должны заполниться автоматически

Альтернативно: Используйте горячие клавиши Alt+Shift+F для заполнения форм
